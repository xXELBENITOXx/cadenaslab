¿Cómo funciona?

Los textos se normalizan, se dividen en secuencias de palabras y se comparan mediante hashing polinómico con un número primo. Cada posible coincidencia se confirma palabra por palabra.

FLUJO DE ANÁLISIS

De dos textos a un resultado

  1. 01
    Normalización

    Se convierten las palabras a minúsculas y se ignoran tildes para la comparación.

  2. 02
    Ventanas de palabras

    Se generan segmentos consecutivos de cinco palabras o menos si el texto es corto.

  3. 03
    Hash polinómico

    Rabin–Karp calcula un valor modular con un número primo.

  4. 04
    Verificación

    Las posibles coincidencias de hash se comprueban comparando las palabras.

  5. 05
    Reporte

    Se calcula el porcentaje de palabras coincidentes y se resaltan fragmentos.

BASE = 911_382_323

# Hash polinómico rodante

    h = (h * BASE + valor) % PRIME

Nota académica importante

El porcentaje refleja similitud literal, no un dictamen de plagio. Citas correctas, textos comunes, paráfrasis y coincidencias accidentales requieren evaluación humana.
